Project Overview

This interactive dashboard explores global CO2 emissions data, helping users understand disparities in per capita emissions and their geographic distribution. The visualizations are designed for the general public, policymakers, and educators.

Numerical Data: CO2 Emissions per Capita (2020)

Analysis

This bar chart shows CO2 emissions per capita for selected countries, with interactive filtering by region and sorting options. High-income countries like Qatar and Kuwait lead in emissions, while developing nations like Nigeria have significantly lower per capita emissions, highlighting global disparities.

Spatial Data: Geographic Distribution of CO2 Emissions

0

Analysis

This interactive map visualizes CO2 emissions by country, with circles colored by emission intensity. Users can zoom, pan, and filter by emission ranges. The map reveals that high emitters are concentrated in the Middle East and North America, while Africa shows lower emissions.

Textual Data: Country Names by Emissions

Analysis

This word cloud displays country names, with font sizes proportional to their CO2 emissions per capita. Larger names indicate higher emissions. Users can search for countries and click names to highlight them in other visualizations, providing an interactive way to explore key contributors to global emissions.

About This Project

This visualization project was created to demonstrate effective data communication principles for HCD:101-00050 (Spring 2025).

  • Audience: General public, policymakers, educators, and students interested in climate change.
  • Key Message: CO2 emissions vary significantly by country and region, with implications for global climate policy.
  • Data Source: Sample data inspired by Our World in Data.

Design Considerations

Following best practices, and the visualizations emphasize:

  • Clear labeling and analysis sections for context.
  • Appropriate chart types: bar charts for numerical data, maps for spatial data, and word clouds for textual data.
  • Interactive elements for exploration across all visualizations.
  • Responsive design for multiple devices.
  • Colorblind-friendly color schemes with vibrant, perceptually uniform colors.
